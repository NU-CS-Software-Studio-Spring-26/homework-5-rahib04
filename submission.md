## Turbo Streams Explanation

Turbo Streams are a Rails/Hotwire feature that lets the server update only part of a webpage instead of forcing a full page reload. Instead of returning a normal HTML page, the server sends back a Turbo Stream response that tells the browser exactly what to change on the page, such as replacing, appending, or removing an element.

In this assignment, the priority toggle updates only the selected todo row instead of re-rendering the entire page.

One thing I verified against the Turbo Streams handbook is that Turbo Stream responses use the MIME type:

```

```

```
text/vnd.turbo-stream.html
```

I also verified that Rails automatically renders matching `.turbo_stream.erb` templates for Turbo Stream controller responses.
